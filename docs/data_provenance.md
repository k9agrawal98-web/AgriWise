# Data provenance

`Crop_recommendation.csv` contains 2,200 rows, 22 classes, and 100 rows per
class. Features are N/P/K/temperature/humidity/pH/rainfall; target is `label`.
The 2026-10-16 audit found no missing values, exact row duplicates, duplicate
feature vectors, identical feature vectors with conflicting labels, or
invalid values under the implemented finite/nonnegative/pH/humidity checks.
Observed feature ranges and class counts are recorded in
`ml/model_metrics.json`.

The original publisher, license, units, geography, collection period,
sampling protocol, sample independence, and target-label definition are not
established by repository evidence. Similarity to a widely circulated
benchmark is not provenance verification. `recommendationData.csv` is an
identical copy, not additional data. Neither file was changed or expanded.
No new source was verified as licensed and compatible for integration, and
no synthetic observations were generated. No nationwide or field accuracy
claim is justified.

The trained classifier uses only N/P/K/temperature/humidity/pH/rainfall.
Location, soil type, moisture, irrigation, season, and farmer outcomes are
not training features. Classifier probabilities are uncalibrated scores, not
field confidence or harvest-success probabilities. Evaluation results and
limitations are documented in `docs/crop_recommendation_improvement.md`.

`crop_knowledge.json` is locally configured knowledge generated by a script
with institution names but no precise traceable references. Treat ranges as
unvalidated educational heuristics. Economic projections are withheld
without `verified_source_url`. Unit compatibility with actual soil laboratory
reports needs verification.

`market_data.json` and `resource_catalog.json` were generated locally. They
are preserved for audit but excluded from operational data loaders. No live
prices, stock, seller identities or history may be inferred from those
fixtures.

Weather: Open-Meteo modeled conditions/forecast, not on-farm sensor
observations. Farmer activities/expenses/sales/soil are explicitly
farmer-entered.

Disease image screening and its bundled checkpoint have been removed.
Problem Report may store a private reference image with farmer-entered
symptoms but does not classify the image.
