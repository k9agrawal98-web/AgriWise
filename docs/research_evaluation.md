# Evaluation

Automated checks include authentication/onboarding, farm persistence, model prediction, expert rules, activity confirmation/isolation/harvest, weather parsing/outage/cache, finance, resource submission, CSRF, image rejection, risk and page routes. Browser script scripts/browser_check.py runs registration/manual setup and page smoke checks in isolated SQLite, records JavaScript errors and a mobile screenshot.

Actual results are recorded in artifacts/verification_results.txt and artifacts/browser_results.json after final execution. This is not the complete 61-step manual acceptance scenario. No farmer field trial, user response study, forecast error benchmark, or agronomic safety validation has been performed.
