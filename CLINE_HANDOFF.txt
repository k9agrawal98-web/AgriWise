AgriWise AI – Cline Handoff and Progress Tracker

============================================================
1. Project Overview
============================================================

Project name:
AgriWise AI: An Intelligent Crop Lifecycle Decision Support System for Sustainable Agriculture

Purpose:
A Flask-based web application for farmers to manage farm setup, crop recommendations, crop lifecycle planning, weather-aware advisory generation, resource discovery, market price analysis, sell planning, and farm finance tracking.

Technology stack:
- Python
- Flask
- SQLite
- Jinja templates
- Bootstrap and custom CSS/JS
- pandas, numpy, scikit-learn, joblib, requests, Pillow, python-dotenv

Application architecture:
- Frontend: Flask templates under templates/ and static assets under static/
- Backend: app.py routes and service modules under services/
- Database: SQLite schema initialized in db.py
- AI/ML: crop recommendation model in services/crop_ml_service.py and ml/train_model.py
- Weather integration: services/weather_service.py
- Market integration: services/official_market_service.py and services/market_service.py
- Lifecycle and advisory logic: services/lifecycle_service.py, services/activity_service.py, services/expert_system.py, services/decision_orchestrator.py
- Finance and planning: services/profit_service.py
- Disease reporting: services/disease_service.py

How to run the application locally:
- Activate a Python environment
- Install dependencies: pip install -r requirements.txt
- Start the app: python app.py
- Open the app in the browser at http://localhost:5000

Important note:
This handoff file is based on repository inspection and git state only. It does not claim a fresh live runtime verification for every feature.

Severity: P2
